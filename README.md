#  Juice Shop Database System

A relational database system designed for a juice shop to manage employees, orders, juices, and sales.

---

##  Features
- Employee management
- Juice menu & pricing
- Order processing system
- Many-to-many relationship between orders and juices

---

##  Tech Used
- MySQL
- Relational Database Design

---

##  Database Structure
Includes tables for:
- Employees
- Orders
- Juices
- Bills
- Order-Juice relationships
